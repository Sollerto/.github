## 👋 Hi there

We're **Sollerto**. We release mods for several games, all powered by our own **universal menu**.
Every feature is built for its specific game, but the menu stays coherent everywhere, so once you know it, you know it.

## 🎮 What we do

- 🧩 **One universal menu** across all our mods
- 🎯 **Game-specific features** tailored to each title
- 🔄 **Consistent experience**, no relearning for every game

## 💡 Get involved

Great mods start with great ideas. Got a feature in mind? **Tell us**, and we'll try to implement it as soon as possible.

👉 Send your ideas to [support@sollerto.de](mailto:support@sollerto.de)
